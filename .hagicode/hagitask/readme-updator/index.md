# README requirements

## Audience and focus

- Address maintainers who run the HagiCode user acceptance tests (Playwright). The README is written in Chinese; keep it in Chinese.

## Required content

- Keep the description of the current acceptance case, local run, environment variables and current assumptions.
- Commands and variable names must match `package.json` and `playwright.config.ts`.

## Exclusions

- Exclude values of environment variables, tokens, internal hosts, machine-specific paths and private links.
